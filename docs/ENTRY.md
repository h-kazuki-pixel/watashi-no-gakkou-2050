### 解決したい課題

公立学校は毎年数百校が廃校になり、学校の規模や配置は全国の自治体の課題です。決めるのは大人ですが、通うのは子どもで、2050年に保護者の世代になるのも今の小学生です。こども基本法は自治体に、こども施策へこどもの意見を反映させる措置を求めています。ところが、子どもが自分の学校の将来を自分で確かめ、根拠をもって意見を言うための材料がありません。将来推計人口はメッシュ単位で公開されていますが、学区の単位では読めず、子どもが読める形にもなっていません。

### 作品の内容

全国の小学校区ごとに、6〜11歳人口の将来推計（2025〜2070年）を国土数値情報から算出し、子どもが次の5ステップで探究するアプリです。

1. ぎもん：いまの人数を見て、2050年を直感で予想する
2. よそう：グラフに自分の予想の線を描く
3. しらべる：データの推計と比べ、学級数やクラス替えの変化を見る。学校の昔の人数を調べて足す
4. なぜ？：年齢の階段で推計のしくみを知り、「もしも」で前提を動かし、同じまちの学校と比べる
5. ていあん：感じ方を整理し、アイデアを選び、データを根拠にした提案カードを作る

ブラウザだけで動き、ログイン不要、氏名を求めず、入力は端末の外に出ません。フォルダごと配ればオフラインでも動きます。45分×2コマの授業案を添えています。

### 使用データ

- 国土数値情報「500mメッシュ別将来推計人口（令和6年国政局推計）」
- 国土数値情報「小学校区データ」
- 文部科学省「廃校施設等活用状況実態調査」（令和6年度）

### 審査基準への対応

- 実用度：算数「データの活用」と社会科の政治の単元に対応。1人1台端末のブラウザで動き、学校の実際の児童数を入れると推計を補正できる。学級数は国の標準（35人学級、複式学級）で計算。
- 完成度：5ステップが動作。学区別推計の生成パイプラインは、手計算できるデータで配分結果と保存則を検算済み。（本応募時点の全国整備状況と授業での試行結果をここに書く）
- 挑戦度：将来推計を、学区という子どもの生活単位で、全国一律に、子ども自身が読む仕組みは、調べた範囲では見当たらない（市町村単位・中高生向けには千葉大学の「未来カルテ」がある。提出前に再確認する）。副産物の「学区別将来児童数」データも公開する。国勢調査と推計の更新（5年ごと）にあわせて再生成できる。
