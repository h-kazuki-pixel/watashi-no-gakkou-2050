# 入賞戦略

2026-11-13 時点。事実として書いたことは末尾の出典で確認したもの、それ以外は方針と見立てです。

## 1. 狙う賞と、勝ち筋

| 賞 | 位置づけ | 根拠 |
|---|---|---|
| データキッズ賞（10万円、1件） | 第一目標 | 子どものデータ利活用・データ学習につながるアプリが対象。今年度の新設とみられ（UDC2025の受賞一覧には無い）、前例に縛られない |
| 一般部門（金50万・銀20万・銅5万） | 第二目標 | 「教育・政治」は今年度の重点分野で、審査の優遇がある |

最終審査はプレゼンのあとの会場投票で決まります。一次審査を通る「完成度」と、会場で票を集める「一言で伝わる物語」の両方が要ります。

**一言**：2050年、きみは34歳。そのとき、わたしの学校は何人？

この一言が効く理由は3つあります。小学4年生は2050年に34歳で、ちょうど保護者の世代になる。学校の規模と配置は全国の自治体が抱える課題で、会場の自治体・インフラ関係者に身近。そして学校は、子どもが当事者として語れるほぼ唯一の公共施設です。

## 2. 審査基準への対応

### 実用度（課題に対して方法が妥当か）

- 教科の内容に乗っている。算数の折れ線グラフ・割合・統計的な問題解決、社会科の政治、総合の地域課題。
- 教室の制約に合う。ブラウザのみ、ログイン不要、氏名を求めない、外部送信なし、オフラインでも動く、ふりがな切り替え、45分×2コマの授業案。
- 学校の実感に合う。全校の人数だけでなく、国の標準（35人学級、複式学級）で学級数とクラス替えの可否に直す。
- 推計の弱点を機能で補う。学区の推計人口と実際の在籍数はずれるので、実際の児童数を入れると全体を補正する。
- 制度と接続する。こども基本法は自治体にこどもの意見の反映を求めている。提案カードはその入口になる。

### 完成度（どこまで具体的に実装・実施されたか）

- いま：5ステップと先生向けページが動く。計算は計算モデルのテスト11件、配分はパイプラインのテスト31件で検算し、ブラウザの通しテスト2本で全ステップを確認済み。福岡県は実データで動作（72市区町村・708校）。
- 本応募までに必須：全国の実データ、公開URL、子どもが実際に使った記録。この3つが揃うかどうかで評価が大きく変わる。

### 挑戦度（新規性・網羅性・継続性・関係者の多様性）

- 新規性：将来推計を、子どもの生活単位である学区で、子ども自身が「予想してから確かめる」形で読む。
- 網羅性：アプリ、学区別将来児童数データ（CSV公開）、授業案の3点セット。
- 継続性：国勢調査と推計は5年ごとに更新される。パイプラインを回せば再生成できる。サーバー不要なので維持費がかからない。
- 関係者：子ども、教員、保護者、教育委員会、議会、地域。カードの宛先として画面に組み込んである。

## 3. 似た取り組みと、ちがい

| 取り組み | 内容 | わたしの学校2050のちがい |
|---|---|---|
| 未来カルテ／未来ワークショップ（千葉大学） | 市町村単位の2040・2050年シミュレーション。中高生が未来市長として政策提言するワークショップを各地で実施 | 単位が市町村ではなく自分の学校。対象が小学生から。進行役がいなくても45分の授業で回せる。データを読む力そのものを学習目標にしている |
| 自治体独自の学校別推計（横浜市の義務教育人口推計表など） | 住民基本台帳をもとに学校別の数年先を推計。精度は高いが、自治体ごと・大人向けの資料 | 全国一律の方法で2070年まで。子どもが読める形。短期の精度は自治体推計が上なので、ある自治体では併用を勧める |
| 不動産情報ライブラリ | 将来推計人口メッシュを地図で表示 | 学区に集計し、学級数に直し、学習の流れに組み込む |

未来カルテは「若者 × 将来推計 × 政策提言」の先行例です。プレゼンでは隠さずに名前を挙げ、「その小学生版・学区版」と位置づけたほうが、審査員の信頼を得られます。本応募の前に、学区単位で子ども向けという組み合わせの先行例がないか、もう一度調べてください。

## 4. 本応募（12/27）までに評価を決める3つ

1. **実データで全国を作る。** まず1県でパイプラインを通し、属性名の判定と配分率を確かめてから全国へ。小学校区データが未整備の自治体は正直に「未対応」と表示する。
2. **子どもに使ってもらう。** 3〜5人でも構いません。予想が外れた瞬間の反応、書いた提案、つまずいた画面を記録する（写真や発言の利用は保護者の同意を取る）。UDC2025では、若者の社会参画を掲げた活動が銀賞と実行委員会特別賞を取り、金賞は学生団体が駐輪場にAIカメラを置いて実地で動かした作品でした。実際に使われた証拠が評価される傾向があると見ています。
3. **公開する。** GitHub Pages とリポジトリ、学区別データの CSV。応募作品は公開可能であることが条件です。

余力があれば次の順で足します。

- クラスモード：全員の予想を1枚のグラフに重ねる（予想のばらつき自体が教材になる）
- 事例帳：空き教室や統合後の校舎の活用例を、出典つきで。行政だけでなく民間・地域が主体の例も入れる
- 過去の実数：国勢調査メッシュから学区別の過去の子ども人口を足し、「これまで」の線を全国で出す
- 中学校区への拡張

## 5. リスクと手当て

| リスク | 手当て |
|---|---|
| 「わたしの学校がなくなる」と受け取られる | 廃校や統合を予測・表示しない。小規模の良さと課題を両方並べる。「決まった未来ではない」をステップ3・4で体験させる。先生向けページに明記 |
| 小さな学区の推計は誤差が大きい | 数人単位の差に意味を持たせない注意書き。実際の児童数での補正 |
| 学区データが古い・未整備 | 整備年度を表示。未整備の自治体は一覧で示す |
| 小学校区データの利用条件 | 自治体ごとに条件が違う。公開前に確認し、条件に合わない自治体は除く（`DATA_METHOD.md`） |
| 学校選択制・私立進学の多い地域 | 「学区に住む子どもの数」であることを明示。補正機能 |

## 6. 最終審査会（2027-02-20）の組み立て

1. 冒頭：会場に聞く。「皆さんの母校、2050年に何人だと思いますか」。その場で1校を開き、予想の線を描く。
2. 赤い線が出る瞬間を見せる。子どもの反応の動画か言葉を添える。
3. 「もしも」のつまみを動かす。推計は前提つきの計算だと伝える。
4. 子どもが書いた提案カードの実物を見せる。届け先（校長、教育委員会など）があれば、その反応も。
5. 締め：全国どの学区でも今日から使える。データとコードは公開している。
